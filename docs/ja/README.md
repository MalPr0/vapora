## 30秒で試す

```bash
curl -fsSL https://github.com/MalPr0/vapora/releases/latest/download/vapora_darwin_arm64.tar.gz | tar -xz
./vapora punch
```

一行が表示されます。それを友人に送り、相手のターミナルに貼り付けてもらってください。

<sup>他のビルド: `darwin_amd64` · `linux_amd64` · `linux_arm64` · `windows_amd64.zip` —— URL の名前を差し替えるだけです。ブラウザではなく `curl` を使ってください。ブラウザはダウンロードしたものを「信頼できない」と印を付け、macOS はその後の実行を拒否します。</sup>

## これが役に立つかもしれない理由

**間に誰もいません。** あなたの言葉はあなたのマシンから相手のマシンへ届きます。どこか
の会社のサーバーも、私のサーバーも通りません。召喚状を突きつける相手も、売り渡す相手
も、侵入される「中間」も存在しません。

**登録するものがありません。** メールも電話番号もユーザー名もプロフィールもありませ
ん。プログラムはあなたが誰かを知りませんし、他の誰も知りません。

**何も保存されません。** 閉じれば会話は両端から消えます。漏れる履歴がないのは、履歴が
そもそも存在しないからです。

**ファイル1つ、依存ゼロ。** バイナリをダウンロードして実行するだけ。Docker もランタイ
ムもインストールも不要です。Go の標準ライブラリだけで作られています——配布されている
コードは一行残らず読めます。

**既定で暗号化、しかも切る方法がありません。** AES-256-GCM、方向ごとに別々の鍵。あな
たが共有する招待そのものが鍵です。

**グループは本物のメッシュです。** 全員が全員と直接話します。5人の部屋にいる2人は、他
の3人には読めないチャンネルを持ちます——ふるまいの約束ではなく、算術としてです。鍵を
持っていないのですから。

## 何に使われているか

- **機微なものを同僚に送る** —— それが会社のチャットログに永遠に残ることなく。
- **ファイアウォール越しに話す** —— ポートを開けることも何かをインストールすることも
  できない場所で。
- **友人との一時的なチャンネル** —— アカウントも履歴も残さず、どちらのマシンにも痕跡を
  残さずに。
- **自分のネットワークを理解する** —— 診断ツールはあなたのプロバイダより多くを教えて
  くれます。

## 2人で

```bash
./vapora punch                 # あなた: 招待を表示します
./vapora punch "<招待>"        # 相手: それを貼り付けて実行します
```

**つながらないときは、両方が招待を送ってください。** 家庭用ルーターはたいてい見知らぬ
相手からのパケットを拒否するので、双方がそうしていると、それぞれの最初のパケットが相
手の玄関先で死にます。相手の画面には *"if it does not connect, send this back"* の下
に一行が表示されます——それを送ってもらい、あなたのターミナルに貼り付ければ、いま2人
は同じ瞬間にノックしています。それこそがルーターが見る必要のあるものです。

その手順が必要かどうかは事前に分かります——[診断](#ネットワークを責める前に知る)を
見てください。

## グループで

```bash
./vapora room                  # 部屋を開いて招待を表示します
./vapora room "<招待>"         # 誰でもそれで参加できます
```

**誰でも招待できます。** 5分前に入ったばかりでも、`!invite` が次の人を呼ぶための一行
をくれます。最初に部屋を開いた人に戻らなくても、全員が全員を知ることになります。

**あなたを招いた人はサーバーではありません。** 2人を引き合わせて、脇へどきます。2人の
間で何も運びませんし、読もうとしても読めません。部屋を開いたマシンを落としても、会話
はそのまま続きます。

**部屋は8人まで**で、**空になると閉じます**——誰もいない部屋は主のいないポートです。
待ち続けさせたいときは `-standalone` を付けてください。

**2人が同じ wifi にいる？** それも動きます。各参加者は公開アドレスとローカルアドレス
の両方を告知します。同じルーターの後ろにいる2台は公開アドレス経由では互いに届かないか
らです。数秒で自動的に解決します。

### 部屋にいる間

| | |
|---|---|
| `@名前` | あなたの行を相手のスクロールから引き上げ、余白に印を付けます |
| `!who` | 誰がいるか、そして各接続がどれだけ健全か |
| `!invite` | 人を呼ぶための新しい招待 |
| `!exit` | 退出し、その場で全員に伝えます |
| `PgUp` / `PgDn` | 話された内容をさかのぼります |
| `-plain` | 全画面ではなくプレーンな行で表示します。何かおかしいときに |

## 仕組み

あなたのパソコンはインターネット上に自分のアドレスを持っていません。持っているのはル
ーターで、家の中のすべてがそれを共有しています。それが **NAT** であり、誰もあなたのノ
ートパソコンを直接「呼び出せない」理由です。よくある答えは、双方が*外向きに*つなぐサ
ーバーを間に置くこと——動きますが、他人のコンピューターが一語残らず見ることになりま
す。

vapora は別のことをします。双方が同じ瞬間にパケットを*外へ*送り、それぞれが自分のルー
ターに穴を開け、その2つの穴が重なります。その後の経路は直結で、他には誰もいません。

| 何 | なぜそこにあるか |
|---|---|
| **UDP ホールパンチング** | 直結経路そのもの。双方が同時に穴を開け、中間で出会います。 |
| **STUN**（[5389](https://www.rfc-editor.org/rfc/rfc5389)、[5780](https://www.rfc-editor.org/rfc/rfc5780)） | 外の世界から見えるあなたのアドレスを調べ、ルーターのふるまいを分類します。 |
| **UPnP-IGD、PCP、NAT-PMP** | ルーターに扉を開けてもらうための3つの言語。3つとも試します。ルーターがどれを話すかで一致することはめったにないからです。 |
| **X25519 + HKDF + AES-256-GCM** | ペアごと、方向ごとに別の鍵。部屋の中で、どのメンバーも他のペアの通信を読めません。 |
| **リプレイ防止ウィンドウ** | 送信者ごとの IPsec 方式スライディングウィンドウ。捕まえたパケットを再生できません。 |
| **BitTorrent DHT**（任意） | アドレスなしで互いを見つけます。既定では無効——[セキュリティ](#セキュリティ)を参照。 |

すべて Go の標準ライブラリです。サードパーティのコードはどこにもありません。

## ネットワークを責める前に知る

```bash
./vapora nat                   # あなたがどんなルーターの後ろにいるか
./vapora diag                  # あなたとインターネットの間にあるすべてのルーター
```

`nat` は `CONE-PORT-18` のような短いプロファイルを表示します。接続したい相手に送り、
相手のものを入れれば、**一晩を無駄にする前に**何が起きるかを教えてくれます。

```bash
./vapora nat -pair CONE-OPEN-64                    # 2人の場合
./vapora nat -room "CONE-PORT-18,SYM-PORT-F3"      # 部屋全体の場合
```

接続できるかどうかは*ペア*の性質であって、どちらか一方の性質ではありません——自分のネ
ットワークをいくら測っても単独では答えられないのです。だからこそプロファイルは他人に
貼り付けるために作られています。部屋の場合はさらに踏み込んで、メッシュが閉じるか、誰
がホストすべきか、そしてどのペアが決して互いに届かないかを教えます。

<sup>ファイアウォールが特定のポートだけ開けているなら、そのポートを測ってください: <code>vapora nat -port 41000</code>。フィルタリングはポートの性質であって、マシンの性質ではありません。</sup>

## セキュリティ

**招待が鍵です。** あの文字列はアドレスではなく、すべてを暗号化している秘密です。パス
ワードと同じように扱ってください。スクリーンショット、グループチャット、肩越し——見た
人は誰でも使えます。

**見知らぬ相手には沈黙。** 正しい鍵を持たないパケットには一切返事をしません。ポートス
キャナが学べることは、閉じたポートから学べることとまったく同じです。ただしそれらは数
えられ、**あなたに知らされます**。ひとつの招待にしか載らなかったはずのアドレスを誰か
が見つけたということだからです。

**あなたの会話は誰にも乗っ取れません。** 招待を第三者に渡しても、その人はあなたの友人
を追い出せません。プログラムは両者を区別し、新参者を無視し、あなたに警告します。

**通るのはテキストだけです。** それ以外は表示されるのではなく捨てられます。そしてネッ
トワークから来たテキストからは、カーソルを動かしたり画面を描き替えたりクリップボード
に触れたりできるエスケープシーケンスが取り除かれます。

**招待はプログラムを閉じるまで有効です。** 期限もなく、失効させる方法もありません。閉
じて開き直すことが失効です——新しい鍵と、たいていは新しいアドレスが手に入ります。

**部屋では、メンバーは他に誰がいるかについて嘘をつけます。** 存在しない人を告知できま
す。できないのは、他の2人が交わす言葉を読むことと偽造することです。でっち上げられたメ
ンバーは決して応答せず、勝手に脱落します。

**「アカウントなし」は「見えない」とは違います。** 話す相手にはあなたの IP アドレスが
見えます。見えなければなりません——パケットはあなたの家から相手の家へ行くのですから。
それが*直接*の意味であり、サーバーを持たないことの正直な代償です。

**`-discover` はあなたのアドレスを公開ネットワークに公表します。** だから既定では無効
です。有効にすると、双方はあなたの秘密から導かれた名前のもとで BitTorrent DHT を通じ
て互いを見つけます。その秘密なしにあなたを探すことは誰にもできませんが、あなたは誰で
も走査できる表の一行になります。

## 何が、いつ壊れるか

正直な限界です。細かい注意書きではありません。

- **STUN サーバーは他人のものです**——Google、Cloudflare、他2社。別の目的のために運営
  されている無料サービスです。なくなれば、このプログラムは自分のアドレスを知ることが
  できず、今のところ代替はありません。
- **端から遮断するネットワークもあります**：企業、大学、ホテル、一部の携帯キャリア。
  あなたの側でできることはありません。
- **そもそも不可能な回線もあります。** *対称型* NAT やキャリアグレード NAT ではアドレ
  スが刻々と変わり、狙う先がありません。`vapora nat` が教えてくれます。唯一の解決策は
  リレーですが、これには意図的にありません。
- **アドレスが変われば招待は死にます。** wifi を切り替える、モバイル回線に移る、十分
  長く放置する。プログラムは気づいて新しいものを表示しますが、送り直すのはあなたです。
- **バージョンは一致していなければなりません。** 通信形式は何度も変わりましたし、また
  変わります。新旧は相互運用できず、症状は*沈黙*です。まず双方が
  `./vapora version` を実行してください。
- **事後の保護はありません。** 今日あなたの通信を記録し、あとで招待を手に入れた人はそ
  の記録を読めます。まともなツールは使い捨ての鍵でこれを解決します。これは違います。
- **バイナリは署名されていません。** OS は警告しますし、それは正しい判断です。
  `SHA256SUMS` でチェックサムを検証するか、自分でビルドしてください。
- **`vapora serve` はルーターの設定を変更します。** これは最初期の UPnP デモで、ここで
  唯一ルーターにインターネットへポートを開けるよう頼むコマンドです。終了時に閉じます
  ——ただしクラッシュした場合、その扉はルーターを再起動するまで開いたままかもしれませ
  ん。この README の他のすべてはルーターに触れません。
- **ソフトウェアを破るのを生業にしている人は誰もこれを見ていません。** 丁寧に作られて
  いることと監査を受けたことは別です。大事なものを賭けないでください。

## これをどう使えるか

<sup>下でリンクしている <code>ARCHITECTURE</code> と Pong のチュートリアルは、いまのところ英語のみです。</sup>

チャットはこのチャンネルの上に作られた一例であって、目的ではありません。トランスポー
トは会話が何かを一切知らない独立した層です。2台のルーターを貫いて暗号化された経路を開
き、メッシュを維持し、**バイト**を運びます。

40行で動くプログラムになります——その2つのコピーが、インターネット上のどこかの2台のマ
シンで、間に何もはさまずバイトをやり取りします。

```go
conn, _ := net.ListenUDP("udp4", &net.UDPAddr{})

codec, _ := punch.NewSecretCodec(secret, punch.RoleInviter)
mux := punch.NewMux(conn)
session := punch.NewSession(mux, codec, nil)
mux.Fallback(session)

session.Observe(punch.ObserverFunc(func(payload []byte) {
    fmt.Println("←", string(payload))       // 送られてきたものを、そのまま
}))

go mux.Run(ctx)
go session.Run(ctx)

session.Open(ctx, 3*time.Minute)             // 両方のルーターを貫きます
session.Send([]byte("hola"))
```

独自の通信形式、何について誰が正しいと決められるのか、そして会話なら台無しになるパケ
ットロスをゲームが生き延びる理由。

```

  ───────────────────────────────────────
    █                    ▄
    █                    █             █
```

| | 送るもの | 気にするもの |

ゲームと会話は同じトランスポートに正反対のことを求めます——鮮度か、確実な到達か——そし
てどちらもトランスポートに変更を求めませんでした。それが、この層分けが本物であること
の最も明快な証拠であり、この上に作ることが誰か他人の決定を引き継ぐことにならない理由
です。

## 自分でビルドする

「このバイナリを信用すべきか」への最も短い答え：

```bash
git clone https://github.com/MalPr0/vapora && cd vapora
go build ./cmd/vapora
go test ./... -race
```

Go 1.25。取ってくるものも設定するものもありません。

`pkg/` の公開宣言はすべて文書化されており、その検査もリポジトリにあります：
`go run ./internal/doclint pkg`。

**構成、読みたい場合は。** `pkg/punch` はハンドシェイク、セッション、部屋。`pkg/stun`
はアドレスを調べて NAT を分類。`pkg/upnp` と `pkg/pcp` はルーターに扉を頼みます。
`pkg/dht` は BitTorrent クライアント。`pkg/diag` は助言の背後にある推論。
`internal/tui` はピクセルアートのチャットです。

[`ARCHITECTURE.md`](../../ARCHITECTURE.md) はそのすべての案内です。
[`AGENTS.md`](../../AGENTS.md) は不変条件を記録しています——細部に見えて、実は建物を支えて
いるものです。こちらは英語のみで、コードの作業用リファレンスだからです。
